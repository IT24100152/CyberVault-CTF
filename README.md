# CyberVault CTF

IE3132 – Penetration Testing
Assignment 02 – Working CTF Play Box

# Project Description

CyberVault CTF is a six-stage cybersecurity
challenge platform developed for educational
penetration testing practice.

# Challenge Stages

1. Hidden Evidence – Steganography
2. Broken Cipher – Cryptography
3. Vulnerable Login – Web Security
4. The Deleted File – Digital Forensics
5. Network Intrusion – Networking
6. Compromised Server – Linux Security

# Technologies
